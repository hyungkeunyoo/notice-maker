안내문 제작기

V1.6.1

GitHub 루트의 chars / logos / templates 구조를 그대로 사용해. A4 인쇄용 안내문 전용 제작기. 웰컴보드는 별도 제작기로 분리했고, 템플릿 목록의 바로가기 카드에서 웰컴보드 제작기로 이동할 수 있어.

1. 용지 · 템플릿

2. 안내문 내용

부분 서식: 제목·부제목·본문·강조문·하단 문구 어디든 원하는 글자만 드래그한 뒤 B 또는 색상을 적용할 수 있어. 이탤릭·밑줄·부분 글자크기는 지원하지 않아.
글자색
미리보기의 제목·부제목·본문·강조문·하단 문구를 직접 드래그해서 위치를 옮길 수 있어.

5. 저장 · 불러오기

PNG는 A4 300dpi 상당 크기, PDF는 실제 A4 규격으로 저장돼. 작업파일은 서버가 아니라 내 컴퓨터에 JSON으로 저장돼.

  • 미리보기에서 제목·부제목·본문·강조문·하단 문구를 각각 직접 드래그해 위치 이동 가능

  • 한양 블루·골드·레드·블랙·화이트 빠른 색상 및 직접 색상 선택 지원
  • 서식 제거 기능 추가

  • 이탤릭·밑줄·부분 글자크기는 의도적으로 지원하지 않음

  • 피드백 메일 전송 및 메일 주소 복사 기능 추가
  • PNG/PDF 출력 파일명 직접 지정 기능 추가

  • 사진 맞춤: 원본 비율 / 영역 맞추기 / 영역 채우기 추가
  • 텍스트와 템플릿 배경의 대비가 낮으면 경고 표시
